# 🧠 코딩 테스트 준비 스터디

Python 기반 코딩 테스트 대비 스터디입니다.  
프로그래머스 LV.3 + 백준 Class 3~5 문제를 중심으로  
문제 해결력, 설명력, 코드 퀄리티를 함께 끌어올리는 것을 목표로 합니다.

---

## 📌 스터디 구성

### 1️⃣ 프로그래머스 스터디

- **모임 시간**: 월요일 오후 7시  
- **장소**: 강남 ~ 송파 인근 카페 or 구글 스타트업 캠퍼스  
- **참고 사이트**: 프로그래머스 LV.3  
- **사용 언어**: Python  

#### 📜 진행 방식

1. 문제 풀이 후 **스터디 당일까지**
   - 스터디 레포에 **주차별 브랜치 push**
   - 개인 브랜치에서 **PR 생성**
2. 스터디 시간에:
   - 문제 풀이 접근 방식 설명  
     > 왜 그렇게 생각했는지, 아이디어 도출 과정
   - 작성한 코드 설명  
     > 적용 알고리즘, 시간복잡도, 구현 포인트
   - 개선 방향 토의  
     > 어려웠던 점, 실패한 접근, 더 나은 방법

---

### 2️⃣ 백준 스터디

- **모임 시간**: 목요일 오후 7시  
- **장소**: 사당 스터디룸  
- **참고 사이트**: 백준 Class 3 ~ 4, 5  
- **사용 언어**: Python  

#### 📜 진행 방식

**[알고리즘]**
1. 문제 풀이 후 **당일 11PM 전까지**
   - 문제 풀이 과정 및 소감 작성
2. **당일 11PM**
   - 디스코드에서 온라인 코드 리뷰
   - 토의 주제:
     - 구현 어려웠던 점
     - 다르게 풀 수 있는 방법
     - 시간/공간 복잡도 개선 아이디어

**[CS]**
1. 매일 메일을 통해 CS 지식 학습
2. 매일 오는 메일 문제에 대한 정답을 노션에 기록
3. 대면 회의 시간에:
   - 이해 안 되는 부분 정리
   - 질문 나올 만한 포인트 토의
   - 개념 정리 및 보완
