## 문제 

 1로 만들기
정수 X가 주어질 때 정수 X에 사용할 수 있는 연산은 다음과 같이 4가지이다.

ㄱ. X가 5로 나누어떨어지면 5로 나눈다.

ㄴ. X가 3으로 나누어떨어지면 3으로 나눈다.

ㄷ. X가 2로 나누어떨어지면, 2로 나눈다.

ㄹ. X에서 1을 뺀다.

네 가지 연산을 사용하여 1을 만들 때, 연산을 사용하는 횟수의 최솟값을 출력하라.

입력 : 1 <= X <= 30,000
